# HuntDownTheEggs_StoreModule
Module for [CS2-Store by Schwarper](https://github.com/schwarper/cs2-store). Config is created at `configs/plugins/HuntDownTheEggs/modules`. <br/>
## Config example:
```json
{
  "Enabled": true,
  "ProviderId": "StorePoints",
  "Rewards": {
    "rare": {
      "100 Store Credits": "100",
      "500 Store Credits": "500"
    },
    "common": {
      "1000 Store Credits": "1000"
    }
  }
}
```
